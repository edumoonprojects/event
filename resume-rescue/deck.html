How to play without phones

Teams, paper and a pen. That’s all.

Make teams of 3 or 4

Each team picks a name and writes it at the top of a sheet of paper.

Write your answer

Write the letter (A, B, C or D). For “tap the line” questions, write the line number and the letter.

Points

100 for each correct answer. Line questions: 100 for the line + 100 for the reason. The last round counts double.

Speak up

Speaking moments earn bonus points. The host decides who gets them.

Before Round 3 · Learn

A strong line = action + what + a number.

Start with an action verb

Built, designed, fixed, led, improved

Say what and with what

A college events website, with HTML, CSS and JavaScript

Add a number

Used by 300 students, 12 bugs fixed, 2nd of 60 teams

Weak → Strong

Did a project on Python.Weak: what? for whom?
Built a Python bot that sends 200 students daily class reminders.Strong: action, what, number
No number?Use people, time saved, or rank

Take it home

The 10-point Resume Checklist

Screenshot this. Check your resume against it tonight.

1 page

A fresher’s resume fits on one page.

Name-based email

Like ravi.kumar@gmail.com, not a nickname.

A specific top line

Who you are + what you’ve built + the role you want.

Projects with numbers

What you built, with what, and how many people used it.

Skills you can explain

If you list it, be ready to answer questions on it.

Proof links

GitHub, a portfolio or a clean LinkedIn URL.

No filler

No “hardworking and honest”, no hobbies like “sleeping”.

Checked by someone else

A friend or senior reads it for typos.

Saved as a PDF

Named like Ravi_Kumar_Resume.pdf.

Updated this semester

Add every new project, internship or win.
