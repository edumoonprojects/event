Before Round 1 · Learn

= puts a value in. == compares.

x = 5

Puts 5 into x

x == 5

Asks: is x equal to 5? Gives true or false

The trap

if (x = 5) puts 5 in x, and 5 is not 0, so C treats it as true. Always.

Example

int x = 3;
if (x = 5) printf("yes");
else printf("no");

Shows

yes (and x is now 5)

Before Round 2 · Learn

An array of 5 goes from [0] to [4]. There is no [5].

int a[5];

5 boxes: a[0], a[1], a[2], a[3], a[4]

The last index

Always size − 1

The trap

i <= 5 reads a[5], memory that isn’t yours. You get garbage or a crash

Example

int a[5] = {1, 2, 3, 4, 5};
for (int i = 0; i < 5; i++)
printf("%d ", a[i]);

Shows

1 2 3 4 5

Before Round 3 · Learn

scanf needs to know WHERE to put the value.

&age

Means “the address of age”: where the box is in memory

scanf("%d", &age);

Read a number and put it in age’s box

The exception

A string (char name[20]) is already an address. No & needed

Example

int age;
scanf("%d", &age);
printf("%d", age);

Shows

Whatever you typed, like 19

Before Round 4 · Learn

Without break, a switch keeps falling into the next case.

case 1:

Where to START running when the value is 1

break;

Where to STOP. Jump out of the switch

The trap

No break: C runs every case below until it finds one

Example

switch (n) {
case 1: printf("one"); break;
case 2: printf("two"); break;
}

Shows

n = 1 prints one. Only one.

Every loop needs a way to stop.

Start and condition

Where does the counter begin, and when does it stop?

Change

Does each run move the counter TOWARDS stopping?

The sneaky one

while (i < 5); with a semicolon is an empty loop that never ends

Example

int i = 1;
while (i <= 3) {
printf("%d ", i);
i++;
}

1 2 3

Take it home

The 10 C Bugs Checklist

Screenshot this. Check every program against it before your lab exam.

= inside if

Use == to compare. = changes the value.

i <= size

Arrays go from 0 to size − 1. Use i < size.

scanf without &

scanf("%d", &n). Strings (char arrays) don’t need &.

Missing break

Each case runs into the next until it hits a break.

A loop that never ends

Check the start, the condition and the change.

; after while, for or if

It ends the statement. The block below isn’t part of it.

int / int

7 / 2 is 3. Use 2.0 or (float) to keep the decimal.

Variable with no start value

Always write int sum = 0; before adding to it.

Missing ; at the end

The error often points to the NEXT line. Look one line up.

Wrong format in printf

%d int, %f float, %c char, %s string.
