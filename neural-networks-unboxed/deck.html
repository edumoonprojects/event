After the sum, an activation function decides the output.

Keep positive numbers; turn negatives into 0

Sigmoid

Why bother?

Without activations, stacked layers act like one simple line

ReLU examples

ReLU(−3)0

Training: measure the error, then nudge the weights.

Loss

One number for how wrong the predictions are

Gradient

Which direction makes the loss go down

Update

new weight = old weight − learning rate × gradient

Like walking downhill in fog

Feel the slopeThat is the gradient
Take a stepSize = learning rate
RepeatUntil you reach the bottom

Before Round 5 · Learn

Overfitting: memorising instead of learning.

The sign

Very high training accuracy, much lower accuracy on new data

Why

Too little data or too big a model for the task

Fixes

More data, simpler model, dropout, stop training early

Like a student who…

Memorised last year’s answersFails new questions
Understood the conceptsHandles new questions
Always test on unseen dataThe real exam

Neural Networks in 8 Lines

Screenshot this. Try computing one neuron with your own numbers.

Neuron

Multiply each input by a weight, add them up, add a bias.

Activation

A rule applied after: ReLU keeps positives and turns negatives into 0.

Layers

Input layer → hidden layers → output layer.

Parameters

All the weights and biases. Training means finding good values for them.

Loss

One number that says how wrong the network is.

Gradient descent

Nudge each weight a little in the direction that lowers the loss. Repeat.

Overfitting

Great on training data, poor on new data. Fix with more data or simpler models.

Today’s giants

CNNs for images, transformers with attention for text. Same basic idea, at huge scale.
