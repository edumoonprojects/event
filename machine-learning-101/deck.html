Before Round 2 · Learn

Learning with answers, or without them.

Supervised

The data has the answers (labels). The model learns to predict them

Unsupervised

No answers. The model finds groups or patterns by itself

Two kinds of supervised

Classification predicts a category; regression predicts a number

Examples

Spam or not spamClassification
How many platesRegression
Group students by eating habitsUnsupervised

Before Round 3 · Learn

Practise on some data. Test on data it has never seen.

Training data

Most of the rows. The model learns from these

Test data

Rows kept aside, hidden from the model while it learns

Why?

Testing on new data shows how it will do in real life

Like exams

Training dataYour practice papers
Test dataThe real exam, with new questions
Testing on training dataLike grading the practice paper you memorised

Overfitting: memorising instead of learning.

It learns the noise too

Even the random one-off nights, like the day the gas ran out

Great on training, poor on new data

That gap is the warning sign

Fixes

More varied data, a simpler model, and always testing on unseen data

Spot it

Training score: 99%Looks amazing
Test score: 60%Falls apart on new data
Big gap = overfittingIt memorised, it didn’t learn

99% accurate can still be useless.

Accuracy = correct ÷ total

Simple, but it can mislead

The rare-case trap

If something is rare, “always no” scores high and catches nothing

Ask what mistakes cost

Some errors are much worse than others

The lazy model

1,000 emailsOnly 10 are spam
Model always says “not spam”Never catches any
Accuracy: 99%Looks great, does nothing

Take it home

8 Machine Learning Words

Screenshot this. These words come up in every AI course and interview.

Features

The inputs the model looks at: day, menu, exam week.

Label

The answer you want to predict: plates eaten.

Supervised learning

Learning from examples that have the answers.

Unsupervised learning

Finding groups or patterns when there are no answers.

Classification vs regression

Predicting a category (spam or not) vs a number (410 plates).

Training and test data

Learn on one part, check on a part the model has never seen.

Overfitting

Memorising the training data instead of learning the pattern.

Bias

A model repeats the unfairness or gaps in its data. Check who’s missing.
