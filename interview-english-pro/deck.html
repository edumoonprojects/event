How to play without phones

Teams, paper and a pen. That’s all.

Make teams of 3 or 4

Each team picks a name and writes it at the top of a sheet of paper.

Write your answer

Write the letter (A, B, C or D). For “tap the line” questions, write the line number and the letter.

Points

100 for each correct answer. Line questions: 100 for the line + 100 for the reason. The last round counts double.

Speak up

Speaking moments earn bonus points. The host decides who gets them.

Before Round 2 · Learn

“I don’t know” is fine. How you say it is what counts.

Never bluff

Interviewers can tell, and it hurts trust

Show how you’d think

“I’m not sure, but here’s how I’d work it out…”

Show how you’d learn

“I haven’t used it yet. I’d start with the official docs…”

Weak → Strong

“I don’t know.” (silence)Gives them nothing
Making something upThe worst option
“I’m not sure, but my guess is… because…”Honest and shows thinking

Before Round 3 · Learn

Structure makes any answer sound smarter.

Say the number first

“There are three main differences.”

Signpost each one

“First… Second… Finally…”

End with a one-line summary

“So the key difference is…”

Useful signposts

“First of all…”Starts the list
“Another point is…”Moves on
“To sum up…”Wraps it up

Before Round 4 · Learn

Asking a question is better than answering the wrong one.

Didn’t hear it?

“Sorry, could you repeat the question?”

Didn’t understand it?

“Just to make sure I understand, are you asking about…?”

Need a moment?

“Let me take a few seconds to think about that.”

Interviewers like it when you

Listen fullyDon’t start answering mid-question
Confirm the questionEspecially long ones
Pause to think5 seconds of thinking beats 5 minutes of rambling

Before Round 5 · Learn

Fewer filler words, more confidence.

Common fillers

“basically”, “actually”, “like”, “you know”, “umm”, “so so so”

Replace them with a pause

A short silence sounds confident

Practise aloud

Record yourself once. You’ll hear your own fillers immediately

Swap these

“Basically, actually…”Just start the sentence
“Umm…”A 1-second pause
“Like, you know…”Say the specific thing
