Before Door 2 · Learn

if / elif / else: the first true one wins.

if condition:

True? Run the indented lines below

elif / else:

Not true? Try the next one

Indentation matters

The spaces show which lines belong to which block

Example

marks = 50
if marks >= 35:
print("Pass")
else:
print("Fail")

Shows

Pass

Before Door 3 · Learn

for loops repeat. range(a, b) stops BEFORE b.

for i in range(1, 4):

i is 1, then 2, then 3. Not 4

total += i

Same as total = total + i

range(5)

Starts at 0: 0, 1, 2, 3, 4

Example

for i in range(1, 4):
print(i)

Shows

1 2 3

Before Door 4 · Learn

Lists hold many values. Counting starts at 0.

marks = [70, 85, 60]

A list of 3 values

marks[0]

The first one: 70

marks[-1]

Negative counts from the end: the last one, 60

Example

marks = [70, 85, 60]
print(marks[0], marks[-1], len(marks))

Shows

70 60 3
